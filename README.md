# MusicDownloader

Скачивание музыки с YouTube / YouTube Music (yt-dlp + ffmpeg): скрипт `download_all.bat` сохраняет FLAC,
графический интерфейс — MP3 320 или FLAC на выбор.
FLAC конвертируется из сжатого (lossy) потока YouTube, поэтому качество равно исходному, а не выше его.

## Установка

Распаковать `ffmpeg.7z` и добавить папку `bin` в `Path` (`sysdm.cpl`). `yt-dlp.exe` лежит рядом со скриптом.

## Использование

- **Плейлист или трек по ссылке:**
  ```
  download_all.bat "https://music.youtube.com/playlist?list=..."
  ```
  Подходят `music.youtube.com/playlist?list=...`, `youtube.com/playlist?list=...`, `watch?v=...&list=...`
  (качается весь плейлист) и ссылки на одиночный трек. Без аргумента скрипт спросит ссылку.
  Треки плейлиста сохраняются в `downloads/<название плейлиста>/<номер> <название>.flac`,
  одиночные — в `downloads/Singles/`. Скачанное записывается в `downloads/archive.txt`,
  поэтому повторный запуск докачивает только новые треки. Недоступные треки пропускаются.
  Доп. параметры yt-dlp можно передать после ссылки, например `--playlist-end 2`.
  Для приватного плейлиста (см. «Вход в аккаунт» ниже) — `--cookies-from-browser chrome` (Chrome закрыть)
  и `deno.exe` рядом с `yt-dlp.exe`: yt-dlp находит его в своей папке сам.
- **Поиск по списку:** запустить без ссылки и нажать Enter — каждая строка `songs.txt`
  ищется на YouTube и сохраняется в `downloads/`.

Ссылка должна быть в кавычках (из-за `&` в URL).

## Графический интерфейс (WPF)

Сборка (нужен .NET 9 SDK):
```
cd gui
dotnet build -c Release
```
Запуск: `gui\bin\Release\net9.0-windows\MusicDownloaderGui.exe`. Программа ищет `yt-dlp.exe` рядом с собой,
затем в родительских папках (корень репозитория); `ffmpeg.exe` и `deno.exe` — рядом с собой, рядом с yt-dlp
или в `PATH`.
Вставьте ссылку, выберите формат и при необходимости папку (по умолчанию `Музыка\MusicDownloader`) и нажмите
«Скачать» («Отмена» останавливает загрузку). Папка и формат запоминаются в `%AppData%\MusicDownloader`
(`folder.txt`, `format.txt`, `login.txt`). Кнопка «Обновить yt-dlp» запускает `yt-dlp -U`. Если ffmpeg не найден, будет предупреждение.

### Вход в аккаунт (приватные плейлисты, «Понравившиеся»)

«Понравившиеся» (`list=LM`) и приватные плейлисты видны только владельцу; без входа YouTube отвечает
`The playlist does not exist`. В списке рядом с папкой выберите вход:
- **Chrome** — перед «Скачать» закройте Chrome полностью (и значок в трее): пока он открыт, база кук
  заблокирована и yt-dlp пишет `Could not copy Chrome cookie database`.
- **Firefox** — закрывать браузер не нужно.
- **cookies.txt** — запасной вариант для любого браузера: в окне инкогнито войдите в YouTube, выгрузите куки
  расширением вроде «Get cookies.txt LOCALLY», закройте окно инкогнито (иначе YouTube быстро сменит куки)
  и положите файл `cookies.txt` рядом с `MusicDownloaderGui.exe`. Когда куки устареют — выгрузите заново.

Куки — это доступ к аккаунту: никому не передавайте `cookies.txt`.

Со входом YouTube отдаёт треки только после JS-проверки, поэтому yt-dlp нужен [Deno](https://github.com/denoland/deno/releases)
(`deno.exe` рядом с программой или в `PATH`, программа передаёт его через `--js-runtimes`). Без него будет
`Signature solving failed` / `Requested format is not available`. Если deno нет, программа при первом
скачивании со входом сама скачает `deno.exe` (~41 МБ) с GitHub в папку yt-dlp.

Форматы (по умолчанию MP3 320):
- **MP3 320** — надёжный выбор для флешки в машине: MP3 читает любая магнитола, FLAC — не все.
- **FLAC** — без потерь относительно потока YouTube, но файлы в 5–6 раз больше.

В оба формата записываются теги (исполнитель, название), чтобы магнитола показывала их вместо имени файла;
обложка не встраивается — большие обложки ломают некоторые магнитолы. Скачанное отмечается отдельно для
каждого формата (`archive-mp3.txt` / `archive-flac.txt` в папке загрузок), поэтому смена формата скачивает
треки заново, а не пропускает их.
